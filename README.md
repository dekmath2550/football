# MatchLens — Football predictions

เลือกลีก ทีมเหย้า และทีมเยือน เพื่อดูโอกาสชนะ–เสมอ–แพ้ สกอร์ที่เป็นไปได้ และสถิติประกอบ

## ข้อมูลจริง

ผลการแข่งขันจาก [OpenFootball](https://github.com/openfootball/football.json) ภายใต้ [CC0-1.0](https://github.com/openfootball/football.json/blob/master/LICENSE.md). รวมพรีเมียร์ลีก ลาลีกา เซเรียอา บุนเดสลีกา และลีกเอิง ฤดูกาล 2025–26 และ 2026–27 เฉพาะแมตช์ที่มีสกอร์จบเกมและไม่อยู่ในอนาคต

ข้อมูลอาจไม่ครบหรืออัปเดตล่าช้า ดูวันล่าสุดในแต่ละลีกบนเว็บ ทีมในเมนูมาจากประวัติทั้งสองฤดูกาล ไม่ใช่รายชื่อสมาชิกลีกปัจจุบัน กดตรวจอัปเดตเพื่อเรียกต้นทางใหม่ในเบราว์เซอร์ หากล้มเหลวจะเก็บชุดข้อมูลเดิม ไม่มี API key และไม่ใช่ผลสด

## โมเดล

Multinomial logistic regression แยกลีก ใช้ Elo ก่อนแข่ง ผลต่างประตู และฟอร์มล่าสุด ฝึกบนช่วงแรก ~80% และทดสอบช่วงท้ายตามวันที่ก่อนฝึกข้อมูลทั้งหมดเพื่อวิเคราะห์แมตช์สมมติในอนาคต สถิติของแมตช์วันเดียวกันคำนวณก่อนวันนั้น ป้องกันการนำผลนัดเดียวกันไปใช้เป็นข้อมูลตั้งต้น

สกอร์คำนวณแยกด้วย independent Poisson จากค่าเฉลี่ยยิง/เสียประตูและ home multiplier 1.12 ยังไม่รวมข่าว ผู้เล่นบาดเจ็บ หรือรายชื่อจริง ผลเป็นความน่าจะเป็น ไม่ใช่คำรับประกัน และยังไม่ได้ปรับเทียบความน่าจะเป็น

## ใช้งาน

เปิด index.html หรือเสิร์ฟโฟลเดอร์นี้ด้วย static server ไม่มี dependencies

GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root) → Save

นำเข้า CSV: date,league,home,away,hg,ag (YYYY-MM-DD, อย่างน้อย 40 นัดต่อลีก) ไฟล์ประมวลผลเฉพาะในเบราว์เซอร์และไม่ถูกส่งขึ้นเซิร์ฟเวอร์ โหลดหน้าใหม่จะกลับชุดข้อมูลจริงที่มากับเว็บ
