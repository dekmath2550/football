# MatchLens

เว็บเลือกทีมเหย้า–ทีมเยือน แล้วแสดงโอกาสชนะ เสมอ แพ้ พร้อมสถิติประกอบ

## ข้อมูลบันทึกครั้งเดียว

ใช้ matches.js ที่บันทึกไว้กับเว็บ จำนวน 1,871 นัดจาก OpenFootball (CC0-1.0) มีข้อมูลล่าสุดถึง 20 กันยายน 2026 ไม่มีการเรียก API จากต้นทาง ไม่มีปุ่มรีเฟรชข้อมูล ไม่มีงานอัปเดตอัตโนมัติ และไม่มีสคริปต์ดึงข้อมูลอีก เปิดหรือรีโหลดเว็บจะใช้ข้อมูลชุดเดิม โดยเบราว์เซอร์โหลดไฟล์เว็บจาก GitHub Pages ตามปกติ

แหล่งข้อมูล: https://github.com/openfootball/football.json
ใบอนุญาตข้อมูล: https://github.com/openfootball/football.json/blob/master/LICENSE.md

## โมเดล

Logistic regression แยกลีก ใช้ Elo ผลต่างประตู และฟอร์มล่าสุด ทดสอบตามลำดับวันที่ด้วยช่วงท้ายประมาณ 20% แล้วฝึกข้อมูลทั้งหมดสำหรับคู่สมมติ สกอร์ประมาณด้วย Poisson แยกจากโมเดลแพ้ชนะ ไม่รวมข่าวหรือรายชื่อผู้เล่น และไม่รับประกันผล
